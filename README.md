# Workspace didático
Base documental da aula “Arquitetura Inteligente e Agentes de IA”. Serve para aprendizagem e organização com continuidade entre sessões e harnesses.

Comece por AGENTS.md ou CLAUDE.md e siga WAKE.md. identity/ define quem é o assistente; memory/ mantém fatos e histórico; state/ guarda a situação atual; governance/ delimita autoridade; journal/ registra sessões; research/ identifica fontes.

outputs/ recebe entregas; evidence/ recebe verificações; archive/ preserva versões pertinentes. Não arquive dados cuja remoção legítima foi solicitada. Nenhuma pasta concede acesso técnico.

Os campos {{NOME_AGENTE}}, {{APELIDO}} e {{RESPONSABILIDADE}} aguardam preenchimento. A base pode ser usada para organização documental enquanto a identidade final permanece pendente. Não há scripts, serviços ou integrações externas neste bootstrap.
